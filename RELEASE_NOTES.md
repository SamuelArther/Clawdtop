New: define words, and pick colors off your screen.

- "define curious" or "what does ubiquitous mean?": he looks it up in a free dictionary and tells you what it means, with an example. (Only if you've let him look things up online.)
- "what color is this?" (or Useful > What color is this?): point your mouse at any color, he counts to three, tells you its name and code (like "sky blue, #78BEF0") and copies the code for you.
- Plus all the fixes from 5.1 to 5.9, including two-monitor and side-taskbar support.

Get him: download the zip, unzip, double-click Clawdtop.bat (Windows) or Clawdtop.command (Mac). Needs Java 22+.
